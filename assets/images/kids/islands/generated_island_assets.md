# Quran journey island artwork

Eight island sprites for the kids whole-Quran journey map
(`KidsIsland` in `lib/features/memorization_plus/domain/services/kids_quran_map_visuals.dart`;
rows cycle through them in enum order).

- Generated by the owner on 2026-10-25 with an image-generation tool of their
  choice, from the prompts in
  `docs/superpowers/assets/2026-10-25-kids-island-image-prompts.md`: a shared
  storybook 2.5D floating-island style prompt plus one subject per island.
- Every prompt excluded text, letters, calligraphy, numbers, signs, logos,
  people and watermarks, and asked for neutral daylight with no baked glow (the
  app adds night glow in code). The book in `island_mushafStand.png` is fully
  closed with a plain cover.
- Delivered as 512 × 512 transparent PNGs. Each was visually checked for
  stray glyphs on 2026-10-25; none found.
- Processing: quantized to a 256-colour palette with alpha (Floyd–Steinberg
  dithering) and saved optimized, cutting the set from 2.3 MB to about
  0.4 MB with no visible difference at the ~160 dp display size.
- Files are declared one by one in `pubspec.yaml`, so this note is not
  bundled. `test/assets/kids_island_assets_test.dart` checks both.
