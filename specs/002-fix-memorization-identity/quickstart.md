# Quickstart: Fix Memorization User Identity

To test the implementation locally:
1. Ensure you have the Flutter application running (`flutter run`).
2. Navigate to the **Memorization** tab.
3. If no path is saved, you will see the **Path Selection Screen**.
4. Selecting **Child** will present the **Guardian Linking Screen** with options to link now or skip.
5. Selecting **Adult** will take you directly to the memorization flow.
6. To test reset, go to **Settings -> Reset/Change Path**.
7. To test parent linking, select **Adult**, go to **Settings -> Enable Parent Mode**, and scan a child's code.
