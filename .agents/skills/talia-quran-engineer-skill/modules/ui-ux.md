# UI/UX

Design for Talia's mobile Quran experience, not for generic engagement metrics.

## Quality Gates

- hierarchy, readability, touch targets, accessibility, loading/empty/error states, navigation clarity, and icon overload.
- Arabic `RTL` and English LTR behavior, directional icons, number/text wrapping, and **text scaling**.
- small-screen and safe-area behavior; mobile-first scope only unless product scope changes.
- focused Quran surfaces remain calm and unobstructed.
- adult surfaces must not become children-only; playful kids treatment stays contextual.
- companion/gamification is secondary to Quran reading, worship, learning, and comprehension.

For redesigns, inspect actual flows and states before proposing visual changes. Verify both primary languages and realistic long content.
