# Quran Integrity

Changes to canonical Quran text, ayah/surah/page relationships, QCF mappings, or persisted canonical identifiers are **Critical**.

Use the authoritative source already defined by the repository/product. Require deterministic validation, affected-range scanning, stored-identifier compatibility, regression coverage, and **broader impact** analysis across reader, bookmarks, audio, memorization, revision, and offline data.

Never use LLM judgment as the canonical validator. Follow [Quran Safety Contract](../references/quran-safety-contract.md). Stop speculative edits when the current canonical source or mapping contract is unclear.
