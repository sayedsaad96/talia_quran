# Git Safety

**Unknown or unrecognized work belongs to the developer until proven otherwise.** Preserve modified/untracked work you did not create.

Safe inspection commands include `git status`, `git diff`, `git log`, `git show`, `git branch`, and `git blame`.

Do not use destructive history/worktree actions without explicit approval and impact understanding, including `git reset --hard`, `git clean -fd`, **force push**, rewriting shared history, or deleting branches/work with unmerged changes.
