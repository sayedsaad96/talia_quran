# Skill Version

Version: 2.0
Last structural review: 2026-09-15

## Major additions

- Hybrid core router with task and risk classification.
- Living repository knowledge templates.
- Domain modules and controlled workflows.
- Evidence-based verification and incident handling.
- Ecosystem intelligence without frozen “latest” versions.

## Known limitations

- Knowledge templates remain `unknown` until verified against the actual Talia repository.
- The skill cannot monitor ecosystem changes in the background; freshness is checked during relevant tasks.
- Behavioral pressure tests still require an agent/runtime to execute them.
