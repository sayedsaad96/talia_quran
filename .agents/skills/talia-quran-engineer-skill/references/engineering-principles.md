# Engineering Principles

## Priority Order

1. Quran/data correctness and religious-content integrity.
2. Privacy, security, and user-data safety.
3. Existing behavior and regression safety.
4. Product usefulness for reading, learning, memorization, revision, listening, and daily practice.
5. Maintainability and fit with the repository architecture.
6. Accessibility, Arabic/English, RTL/LTR, and mobile usability.
7. Measured runtime performance and responsiveness.
8. Visual polish and delight.
9. Novelty.

## Rules

- **Unknown is not assumed.** Search, inspect, measure, or label unknown explicitly.
- **Smallest safe change.** Fix only what serves the task plus the minimum enabling refactor.
- Repository evidence beats remembered assumptions and living-knowledge notes.
- A new technology is not an improvement until it solves a real Talia problem with acceptable risk.
- Preserve existing user data and unrecognized developer work.
- Distinguish verified defects, high-confidence risks, improvement opportunities, and future ideas.
