# Performance Investigation Workflow

1. Define the user-visible metric/problem.
2. Capture a **Baseline** in the relevant mode/device.
3. **Profile** the real flow.
4. Locate the actual **Bottleneck** and state a hypothesis.
5. Change one meaningful cause; do not mix unrelated optimizations.
6. **Measure again** under comparable conditions.
7. Report `Measured improvement`, `Measured regression`, `No meaningful difference`, or `Not measured` with evidence.
