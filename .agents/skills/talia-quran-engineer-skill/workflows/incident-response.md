# Incident Response Workflow

Record incident type, `SEV-0..SEV-3`, reproducibility `R0..R3`, environment, and blast radius.

`Detect → Contain → Gather Evidence → Reproduce → Trace Root cause → Hypothesis → Experiment → Minimal Fix → Regression Test → Verify → Document Cause → Prevent Recurrence`

**Contain** further harm first when needed; containment is temporary risk reduction, not proof of resolution. Do not repair corrupted data before understanding the corruption mechanism. Quran/data/security incidents require the higher risk contract and deterministic verification.
