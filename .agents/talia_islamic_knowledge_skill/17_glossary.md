# 17 — Glossary (Quick Reference)

## Purpose
A compact, alphabetically-scannable companion to `11_islamic_terminology.md` for fast lookup during development — short definitions only; see module 11 for full context and software implications.

## Overview
Use this when you just need a quick definition; use `11_islamic_terminology.md` when you need to understand how a term should shape a design or code decision.

## Glossary

| Term | Short definition |
|---|---|
| Adhkar (أذكار) | Prescribed/recommended remembrances tied to times or situations |
| Asbab al-Nuzul | Occasions/circumstances of a verse's revelation |
| Athar (أثر) | A report from a companion or early generation, not the Prophet ﷺ directly |
| Ayah (آية) | A single verse of the Quran |
| Basmalah | "Bismillah al-Rahman al-Rahim," recited at the start of most surahs |
| Da'if (ضعيف) | Weak hadith grading |
| Dua (دعاء) | Personal supplication |
| Fiqh (فقه) | Islamic jurisprudence |
| Hadith (حديث) | A reported saying/action/approval of the Prophet ﷺ |
| Hafs 'an 'Asim | The most widely used Quranic reading/riwayah globally |
| Hasan (حسن) | Good (reliable, slightly weaker than Sahih) hadith grading |
| Hifz (حفظ) | Quran memorization |
| Hizb (حزب) | Half a juz' (60 total in the Quran) |
| Isnad (إسناد) | Chain of narrators for a hadith |
| Juz' (جزء) | One of 30 parts of the Quran |
| Khatm (ختم) | Completing a full reading of the Quran |
| Madd (مد) | Vowel elongation rule in tajweed |
| Madani | Revealed after the Hijrah (Medinan) |
| Madhab (مذهب) | A school of Islamic jurisprudence |
| Makharij al-Huruf | Articulation points of Arabic letters |
| Makki | Revealed before the Hijrah (Meccan) |
| Matn (متن) | The text/content of a hadith (vs. its chain) |
| Mawdu' (موضوع) | Fabricated hadith grading |
| Mawquf (موقوف) | A report attributed to a companion, not the Prophet ﷺ |
| Muhkam (محكم) | Verses with clear, unambiguous meaning |
| Muraja'ah (مراجعة) | Revision/review of memorized material |
| Mushaf (مصحف) | A physical or rendered copy of the Quran text |
| Mutashabih (متشابه) | Verses with meaning scholars differ on / not fully knowable |
| Naskh (نسخ) | The concept of one ruling superseding another (contested, fiqh-level) |
| Qalqalah (قلقلة) | A bounce/echo on certain letters carrying sukoon |
| Qari' (قارئ) | A scholar/reciter a canonical reading is named after |
| Qira'at (قراءات) | Canonical Quranic reading traditions |
| Rawi (راوي) | A narrator/transmitter of a specific reading |
| Riwayah (رواية) | A specific transmitted reading tradition (e.g., Hafs 'an 'Asim) |
| Rub' al-Hizb (ربع الحزب) | A quarter of a hizb (240 total in the Quran) |
| Sahih (صحيح) | Authentic hadith grading |
| Sajdah (سجدة) | A verse calling for prostration upon recitation |
| Salaf | The early generations of Muslims |
| Sifat al-Huruf | The manner/quality of a letter's pronunciation |
| Sunnah (سنة) | The Prophet's ﷺ practice/example |
| Tafsir (تفسير) | Scholarly interpretation/exegesis of the Quran |
| Tajweed (تجويد) | Rules of correct Quranic pronunciation |
| Tilawah (تلاوة) | Recitation of the Quran |
| Waqf (وقف) | Rules for pausing during recitation |
| Wird (ورد) | A regular committed portion of recitation/review |
