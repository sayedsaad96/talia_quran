# وثيقة تصميم وتطوير تجربة الأذكار والأدعية (Azkar & Duas UI/UX Design Spec)

**التاريخ:** 2026-09-10  
**المشروع:** تطبيق تاليا القرآني (Talia Quran)  
**الحالة:** معتمد من المستخدم (Approved)  

---

## 1. الملخص التنفيذي والأهداف (Executive Summary & Goals)

تهدف هذه الوثيقة إلى إحداث نقلة نوعية شاملة في تجربة المستخدم (UI/UX) لصفحات الأذكار والأدعية في تطبيق تاليا القرآني، مع الالتزام الصارم بالهوية الروحانية الراقية للتطبيق (Talia Luxury & Serene Spiritual Aesthetic)، وتحقيق أقصى درجات الراحة والانسيابية أثناء القراءة والتسبيح والتعبد:

1. **الصفحة الرئيسية (Azkar Hub):** تحويلها من قائمة ثابتة إلى واجهة حيوية ذكية تتكيف زمنياً (Dynamic Time-Context Hero) وتبرز الورد المستحق (الصباح / المساء) مع شريط إنجاز يومي مباشر وزر تفاعلي بنقرة واحدة، تليها شبكة أقسام بصرية منظمة (Bento Grid) ومسبحة إلكترونية حرة سريعة.
2. **شاشة القراءة والتسبيح (Azkar Category / Recitation):** تمكين وضع التسبيح الحر التفاعلي الكامل (Full-Card Tap) مع اهتزاز لمسي خفيف (Micro-Haptics)، وانتقال تلقائي ذكي للذكر التالي (Auto-Advance) عند إتمام العدد مع مفتاح تحكم سريع، ودمج العداد الدائري الانسيابي، وإبراز فضل الذكر وتوثيقه.
3. **مكتبة الأدعية والمفضلة (Duas & Favorites Library):** إتاحة شريط بحث لحظي فوري (Real-time Search)، تنظيف وتوحيد التبويبات الموضوعية، تدشين نظام حفظ الأدعية في المفضلة (Persistent Bookmarks)، وتوفير أداة التحكم بحجم الخط.
4. **إثراء المحتوى القرآني والنبوي المعتمد:** إضافة أدعية نبوية مأثورة عالية الأهمية والحاجة (مثل: دعاء الاستخارة، تفريج الكرب وقضاء الدين، السفر، عيادة المريض) مع التوثيق المعتمد وتصحيح التسميات المكررة.

## 2. التصميم المفصل للمكونات (Detailed Component Specifications)

### أولاً: الصفحة الرئيسية للأذكار (`AzkarPage` - `lib/features/azkar/presentation/pages/azkar_page.dart`)

```
+-----------------------------------------------------------+
|                   سياق اليوم والترحيب                    |
|   "ألا بذكر الله تطمئن القلوب" • 28 صفر 1448             |
+-----------------------------------------------------------+
| [ بطاقة الورد الذكية المقترحة بحسب الوقت - HERO CARD ]   |
|   ☀️ أذكار الصباح (أو 🌙 أذكار المساء)                    |
|   التقدم اليومي: [████████░░░░░░░░] 14 من 22              |
|   [ متابعة الورد / ابدأ الآن ]  (زر بنقرة واحدة)          |
+-----------------------------------------------------------+
|             شبكة الأقسام المنظمة (Bento Grid)             |
|  +---------------------------+-------------------------+  |
|  | ☀️ أذكار الصباح (22 ذكر)   | 🌙 أذكار المساء (22 ذكر) |  |
|  +---------------------------+-------------------------+  |
|  | 🤲 أدعية القرآن والسنة    | 📿 مسبحة إلكترونية حرة  |  |
|  |    (مكتبة مصنفة + بحث)    |    (33 / 100 / مفتوح)   |  |
|  +---------------------------+-------------------------+  |
|  | 🌿 أذكار عامة ومتنوعة (بعد الصلاة، النوم، الاستيقاظ)   |  |
|  +-----------------------------------------------------+  |
+-----------------------------------------------------------+
```

1. **محرك الوقت الذكي (Time Context Engine):**
   - دالة مساعدة تحسب الوقت الحالي:
     - من الفجر (أو 04:00) حتى ما قبل العصر (15:30): يُبرز **أذكار الصباح** بتدرج شروق مذهب دافئ (`AppColors.primaryLight` إلى `AppColors.primary`).
     - من العصر (15:30) حتى نهاية الليل (03:59): يُبرز **أذكار المساء** بتدرج ليلي كحلي مهيب (`AppColors.primary` إلى `AppColors.darkBackground`).
   - قراءة نسبة الإنجاز اللحظية من `AzkarCompletionStore` وعرضها في شريط تقدم انسيابي.
   - الزر الرئيسي ينقل المستخدم مباشرة إلى `/azkar/morning` أو `/azkar/evening` لأول ذكر لم يُتم بعد.

2. **شبكة الأقسام المنظمة (Curated Bento Grid):**
   - بطاقات عصرية متناسقة بأركان ناعمة (`borderRadius: 20`) وتأثير ضغط تفاعلي ناعم (`scale: 0.97`).
   - تضمين زر/بطاقة **"المسبحة الإلكترونية الحرة"** التي تفتح نافذة سفلية تفاعلية سريعة.

### ثانياً: شاشة القراءة والتسبيح التفاعلية (`AzkarCategoryPage` - `lib/features/azkar/presentation/pages/azkar_category_page.dart`)

1. **التسبيح بالنقر الحر (Full-Card Tap Area):**
   - تغليف كامل بطاقة القراءة بـ `GestureDetector`، بحيث يمكن النقر في أي مكان داخل بطاقة الذكر للزيادة الفورية في العداد.
   - إبقاء العداد الدائري البصري كعنصر تغذية بصرية (Visual Feedback) يوضح النسبة المتبقية `الحالي / الإجمالي`.
   - **اهتزاز لمسي (Haptic Feedback):**
     - نقرة خفيفة (`HapticFeedback.lightImpact()`) مع كل تسبيحة.
     - اهتزاز قوي مميز (`HapticFeedback.heavyImpact()`) عند إتمام عدد الذكر.

2. **الانتقال التلقائي الذكي (Auto-Advance):**
   - عند بلوغ العدد المحدد للذكر:
     1. ظهور وميض/علامة إتمام مباركة خضراء.
     2. تشغيل انتقال متحرك سلس (Smooth Slide) بعد 350 مللي ثانية تلقائياً إلى الذكر التالي عبر `_pageController.animateToPage`.
   - إضافة مفتاح تشغيل/إيقاف في شريط التطبيق العلوي (`Icons.autorenew_rounded` أو `Icons.play_circle_outline_rounded`) يتيح للمستخدم إيقاف أو تفعيل الانتقال التلقائي مع حفظ التفضيل.

3. **الهيكل البصري لبطاقة الذكر (`_ZikrReaderPage`):**
   - الخط العربي الأصيل (`Amiri`) مع مسافات مريحة وتدرج خطوط ديناميكي (3 أحجام).
   - قسم مخصص بلون ذهبي هادئ لـ **فضل الذكر (Virtue)** إن وُجد، يعزز اليقين واستحضار النية.
   - أسفل النص: التخريج والرتبة التوثيقية للحديث.
   - في الأسفل: حزام عداد مدمج أنيق يحتوي على مؤشر التقدم الدائري، زر التراجع السريع عند الخطأ، وزر القفز المباشر للفهرس.

### ثالثاً: مكتبة الأدعية والمفضلة (`GeneralAzkarPage` - `lib/features/azkar/presentation/pages/general_azkar_page.dart`)

1. **شريط البحث اللحظي (Instant Real-time Search):**
   - حقل بحث علوي مدمج في شريط الأدوات مع أيقونة بحث وزر مسح سريع `Clear`.
   - تصفية فورية لنصوص الأدعية، العناوين، والتصنيفات الفرعية.
   - واجهة مخصصة عند عدم العثور على نتائج، مع زر لإعادة ضبط البحث.

2. **التصنيفات الموضوعية الموحدة (Unified Clean Chips):**
   - معالجة وإزالة التكرار القديم ("أدعية من القرآن" و"أدعية قرآنية").
   - التبويبات الرسمية:
     1. `الكل`
     2. `المفضلة ❤️`
     3. `أدعية من القرآن`
     4. `أدعية نبوية`
     5. `دعاء ختم القرآن`
     6. `جوامع الدعاء ومناسبات` (السفر، الاستخارة، المريض، تفريج الكرب)

3. **نظام المفضلة المحلي المستمر (`AzkarFavoritesStore`):**
   - فئة تخزين تعتمد على `SharedPreferences` لحفظ قائمة معرفات الأدعية المفضلة (`Set<String>`).
   - زر مفضلة (أيقونة قلب / Bookmark) على كل بطاقة دعاء:
     - عند النقر: اهتزاز لمسي خفيف + تبديل حالة الحفظ فورياً.
     - تبويب "المفضلة" يعرض فقط الأدعية المحفوظة مع رسالة توجيهية عند فراغها.

4. **التحكم بالخط والمشاركة:**
   - زر دوراني في شريط الأدوات العلوي لتكبير وتصغير خط الأدعية (3 درجات خط).
   - أزرار سريعة للنسخ والمشاركة كبطاقة مصممة (`SocialShareSheet`).

### رابعاً: المسبحة الإلكترونية الحرة السريعة (`FreeTasbeehBottomSheet`)

مكون جديد خفيف وسهل الوصول من الواجهة الرئيسية:
- خيارات الورد الحر: 33 (تسبيح دبر الصلوات)، 100 (استغفار وتهليل)، أو عداد مفتوح.
- مساحة نقر عريضة مع صوت/اهتزاز لمسي هادئ.
- زر إعادة الضبط (Reset) مع تأكيد لمنع المسح بالخطأ.

---

### خامساً: إثراء محتوى الأدعية (`assets/data/azkar_release.json`)

إضافة أدعية مأثورة صحيحة وموثقة تفتقر إليها المكتبة الحالية:
1. **دعاء الاستخارة:** (اللَّهُمَّ إِنِّي أَسْتَخِيرُكَ بِعِلْمِكَ وَأَسْتَقْدِرُكَ بِقُدْرَتِكَ...) — صحيح البخاري.
2. **دعاء تفريج الكرب وقضاء الدين:** (اللَّهُمَّ إِنِّي أَعُوذُ بِكَ مِنَ الْهَمِّ وَالْحَزَنِ... / اللَّهُمَّ اكْفِنِي بِحَلَالِكَ عَنْ حَرَامِكَ...) — الترمذي وحسنه.
3. **دعاء السفر:** (اللَّهُ أَكْبَرُ، اللَّهُ أَكْبَرُ، اللَّهُ أَكْبَرُ، سُبْحَانَ الَّذِي سَخَّرَ لَنَا هَذَا...) — صحيح مسلم.
4. **دعاء عيادة المريض والشفاء:** (أَسْأَلُ اللَّهَ الْعَظِيمَ رَبَّ الْعَرْشِ الْعَظِيمِ أَنْ يَشْفِيَكَ) — أبو داود والترمذي وصححه الألباني.
5. **سيد الاستغفار في قسم الأدعية:** لسهولة الوصول إليه كدعاء مستقل.

*جميع الإضافات تستوفي معايير `approved_azkar_content.dart`: معرفات فريدة، رتب صحيحة/حسنة، مراجعة وتوثيق دقيق.*

## 3. المعمارية وتدفق البيانات (Architecture & Data Flow)

```
[UI Layer]
  AzkarPage (Hub)
    ├── Reads Completion -> AzkarCompletionStore
    ├── Time Context Engine -> Morning/Evening Hero State
    └── FreeTasbeehBottomSheet

  AzkarCategoryPage (Recitation)
    ├── AzkarCubit (Session & Counts)
    ├── FullCardTap GestureDetector -> Haptics + Cubit.increment()
    └── AutoAdvance Controller -> PageController.animateToPage()

  GeneralAzkarPage (Library)
    ├── AzkarCubit -> Load Category/Duas
    ├── Search & Filter Query (Real-time in memory)
    └── AzkarFavoritesStore -> Persistent Favorites (SharedPreferences)

[Data Layer]
  AzkarLocalDataSource -> assets/data/azkar_release.json
  AzkarRepositoryImpl -> Caching & Entity mapping
  AzkarFavoritesStore -> SharedPreferences ('favorite_azkar_ids')
```
