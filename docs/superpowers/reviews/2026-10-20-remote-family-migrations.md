# الدفعة G — هجرات محلية قيد التحقق

أُنشئت ثلاثة ملفات بواسطة Supabase CLI المحلي 2.116.0، ونُفّذ SQL حسب
تصميم G0. بدأ لاحقًا ربط واجهات العميل بالخطة والوعود ورسائل التشجيع؛
التحقق النهائي منها ما زال جاريًا. لا يوجد تطبيق على Supabase أو نشر.
جميع أعلام الميزات مطفأة. هذه حالة تنفيذ، وليست اعتمادًا أمنيًا للهجرات.

- سياسة الطفل v2 لولي الأمر المرتبط فقط، بثلاثة حقول اختيارية وحدودها.
  يشترك الإصداران في عدّاد التعارض؛ يظل SQL القديم كما هو ويحفظ الحقول الجديدة.
- إنشاء الوعد v2 مع شرط السورة، وفتح الشرط من الطفل نفسه مع رابط نشط.
  لا يثبت الخادم الحفظ؛ يبقى طلب الهدية واعتماد تسليمها مسارين منفصلين.
- رسائل بقائمة نصوص وملصقات ثابتة، ومعرّف طلب لمنع تكرار الإرسال.
  حد العشر رسائل لكل طفل في يوم UTC محفوظ في صف مستقل ضمن المعاملة نفسها.
  القراءة مرتبطة بالرابط الأصلي النشط، والكتابة عبر RPC فقط.

أُضيف فاحص لعقود المعاملات والنتائج وEXECUTE وSECURITY DEFINER وsearch_path
والجداول وRLS والصلاحيات. تُشغّله أداة التحقق الحالية تلقائيًا.
وتوجد حالات SQL تتراجع عن تغييراتها للتحقق من توافق v1، والتعارض، وشرط
الهدية، والتكرار والحد اليومي، وتعليم الرسائل مرئية، وعزل القراءة وسحب الرابط.
الاختبارات النصية المحلية ناجحة. ونجح تنفيذ الهجرات الثلاث، و32 استعلامًا
فعليًا من فاحص العقود، وحالات SQL القابلة للتراجع على PostgreSQL 18.6
داخل PGlite 0.5.10 المعزول. أُعيد استخدام تعريفات الجداول وRPCs القديمة
المعنية؛ استُخدمت تهيئة اختبارية لـ auth.uid والأدوار وجدول المستخدمين.
ثبت تنفيذ تلك العقود وعزل القراءة والتراجع في هذا السياق المحدود.
لا يُعد ذلك تشغيل سلسلة هجرات Supabase الكاملة أو تحقق JWT أو اختبار التزامن.

المتبقي: تشغيل الفاحصين على قاعدة Supabase اختبار فارغة وقاعدة ترقية،
واختبارات متزامنة بجلسات متعددة والتحقق الفعلي من الصلاحيات. نُفّذ ربط
العميل G1–G3 والحفاظ على أصل الهدية المحلية والسحابية، مع مراجعة حدود
محلية موثّقة في [سجل العميل](2026-10-21-remote-family-client.md).
لا تتوفر حاليًا أداة psql
أو Docker في المسار، ولم يُستخدم عنوان قاعدة بيانات. النشر يحتاج موافقة
المالك بعد اكتمال هذه الأعمال وعرض النتيجة الملموسة.

رُوجعت [وثائق الدوال](https://supabase.com/docs/guides/database/functions)
و[عزل الصفوف](https://supabase.com/docs/guides/database/postgres/row-level-security)
عند التنفيذ. تعذر جلب فهرس changelog بصيغة Markdown من أداة التصفح؛
لم يُستنتج من ذلك خلو التغييرات الحديثة من تغييرات مؤثرة.

المحرك الإضافي مُثبّت بإصدار محدد في مجلد الاختبار المؤقت فقط، دون إضافة
تبعية للتطبيق. يوفّر [PGlite](https://pglite.dev/docs/) اتصالًا واحدًا؛ لذلك
تبقى اختبارات السباقات متعددة الجلسات خارج نطاق هذا الدليل.
