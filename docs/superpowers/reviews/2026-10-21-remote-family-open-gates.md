# الدفعة G — بوابات التفعيل المفتوحة

هذه قائمة تحقق قبل التفعيل، وليست طلب موافقة على النشر الآن.
الموافقة النهائية تأتي بعد تجهيز دليل الاختبار والنتيجة الملموسة.

| البوابة | الدليل الموجود | ما لا يزال مطلوبًا |
|---|---|---|
| عقد SQL | تنفيذ الهجرات الثلاث و32 استعلام فحص وحالات RLS متتابعة داخل PostgreSQL/PGlite | تشغيل `scripts/verify_supabase_migrations.ps1` على قاعدة Supabase اختبار فارغة، ثم `scripts/verify_supabase_contract.ps1` على قاعدة ترقية |
| المصادقة والصلاحيات | فحص التعريفات وACL وRLS، ومراجعة Astra قراءةً فقط | JWT وPostgREST بحسابات ولي أمر وطفل وغير مرتبطين على قاعدة الاختبار |
| التزامن | قفل صف الرابط وحارس الحصة اليومية وCAS في SQL | طلبا CAS متعارضان، و11 إرسالًا متزامنًا، وإعادة الطلب نفسه، وسحب الرابط أثناء الانتظار بجلسات مستقلة |
| استكمال جلسة قديمة | اختبارات الفحص والاختيار والإلغاء وفشل الحفظ وعزل الحساب | تجربة المسار المباشر والاستئناف في المغامرة ورحلة القرآن على Android |
| الإشعارات | اختبارات الأيام والإلغاء والعودة إلى التذكير اليومي | أيام الاثنين والأحد وتغيّر المنطقة الزمنية وإعادة التشغيل على الجهاز |
| التشجيع | اختبارات العرض العربي الضيق والإرسال وإيصالات «تم» وإعادة المحاولة | مزامنة بين جهازين، وقطع الاتصال، وسحب الرابط وإعادته |
| النشر | ملفات هجرات محلية وفاحص وSQL قابل للتراجع | موافقة المالك بعد إغلاق البوابات السابقة |

لا يُستخدم مشروع الإنتاج قاعدةً للاختبار. لم يتوفر أثناء التنفيذ `psql`
أو Docker، ولم يُستخدم عنوان قاعدة بيانات خارجية. يبقى عنوان قاعدة
Supabase الاختبارية وأدوات تشغيل الفاحصين متطلبًا لاستكمال هذه البوابة.

أعلام الدفعة الثلاثة مطفأة، ولم يُنشأ commit أو push أو نشر لهذه التغييرات.
متطلبات المتشابهات في E منفصلة: يلزم تصنيف العينة المرشحة يدويًا، ثم
المعايرة واعتماد الفهرس المشتق قبل إتاحته.
