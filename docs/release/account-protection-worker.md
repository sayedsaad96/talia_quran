# Account protection worker handoff

Status updated 2026-11-01: parent integration completed the backup page, preview/confirmation, evidence provider, localization, DI and feature gates. This is not release acceptance. See the authoritative [integration report](2026-10-31-three-initiatives-validation.md); the paragraphs below describe the worker's original handoff.

`PortableSignedInImporter` requires the app's shared owner, bound `AccountDataBarrier`, shared `RestoreOperationGate`, `BookmarkService`, preferences and corpus-backed bookmark resolver. `preview` returns additions, existing references, tombstone conflicts, invalid references and optional source/current checkpoints. It retains an account-generation lease and fingerprints the complete durable bookmark snapshot including tombstones plus the current checkpoint. `apply` rechecks these before adding only missing references and, only when explicitly selected, writes the provided checkpoint. Existing live/tombstoned entries remain unchanged; bookmark content is rebuilt from the corpus resolver, never imported text, sync flags or owner IDs. Other backup sections are ignored by this API.

Resolution: writes remain additive and not crash-atomic; the parent implemented `BookmarksOnlyCheckpointFailed` with explicit UI reporting and retry tests. Success of the bookmark additions is preserved and never reported as no change. Owner transitions and pending checkpoint retention have local tests; device/restart acceptance remains pending. The status loader uses per-domain evidence and leaves unknown values unknown. Full replacement is separately blocked for writer/isolate exclusion, as detailed in the integration report.

Focused tests: `flutter_tools.snapshot test --no-pub test/features/settings/data_protection_cubit_test.dart test/core/backup/portable_signed_in_import_test.dart` passed 3 tests (account switch, stale bookmark snapshot, tombstones, checkpoint selection/conflict and independent per-domain status). Original tests were observed failing before implementation. Android, accessibility, crash recovery, security review, full suite and integration wiring remain unverified.
